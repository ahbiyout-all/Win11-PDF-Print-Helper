# 🛠️ 프린터 상태 진단 및 트러블슈팅 가이드 (Printer Diagnosis Guide)

본 문서는 Win11 PDF Print Helper의 프린터 상태 모니터링 시스템, 윈도우 인쇄 스풀러 상태 코드, 그리고 마우스 호버 진단 툴팁 기능에 대해 안내합니다.

---

## 1. 프린터 상태 진단 툴팁 (.printer-status-indicator)

프린터가 선택되면 상단 헤더 및 드롭다운 항목 옆에 상태 인디케이터 배지가 나타납니다.
해당 배지에 마우스를 올려놓으면(Hover) 상세 진단 툴팁이 활성화됩니다.

## 2. 윈도우 스풀러 주요 상태 코드 및 진단 정보

`getPrinterStatusDiagnosis()` 매핑 엔진을 통해 각 상태 코드에 대응하는 원인 및 해결 조치 사항을 제공합니다.

| 상태 코드 | 상태 구분 | 상태 이름 | 상세 의미 | 권장 조치 사항 |
| :---: | :---: | :---: | :--- | :--- |
| **0** | Success | 준비 완료 (Ready) | 프린터가 인쇄 명령을 받을 준비가 됨 | 정상 상태입니다. 바로 인쇄를 진행하세요. |
| **1** | Warning | 일시 정지 (Paused) | 프린터 작업이 일시 정지됨 | 윈도우 제어판 '장치 및 프린터'에서 '인쇄 일시 중지' 해제 |
| **2** | Error | 프린터 오류 (Error) | 하드웨어 또는 드라이버 오류 | 인쇄 대기열 삭제 후 프린터 전원 재부팅 |
| **3 / 9** | Error | 오프라인 (Offline) | 전원이 꺼져 있거나 연결 끊김 | USB 케이블 / 네트워크(Wi-Fi/LAN) 연결 점검 |
| **4** | Error | 용지 걸림 (Paper Jam) | 이송 경로에 용지가 걸림 | 덮개를 열고 걸린 용지를 천천히 제거 |
| **5** | Warning | 용지 부족 (Paper Empty) | 급지 트레이에 용지가 없음 | 용지함에 A4 등 규격 용지 공급 |
| **6** | Warning | 급지 오류 (Paper Problem) | 용지 크기 불일치 또는 미끄러짐 | 인쇄 용지 설정 크기 확인 및 정렬 |
| **7 / 15**| Warning | 토너/잉크 부족 (Toner Low) | 카트리지 소모품 잔량 소진 직전 | 카트리지를 꺼내 좌우로 흔들거나 새 제품 교체 |
| **8** | Success | 인쇄 진행 중 (Busy/Printing)| 다른 작업 실행 중 | 완료될 때까지 잠시 대기 |

## 3. 프린터 상태 복구 감지 및 알림 (Recovery Notification)

### 1) 오프라인 ➡️ 준비 완료 자동 감지
- 프린터 케이블을 재연결하거나 전원을 켰을 때, 백그라운드 스캔(30초 주기)을 통해 상태 변화가 감지됩니다.
- 상태 변화 즉시 `.printer-status-indicator` 요소가 **녹색 강조 링(ring-4 ring-green-500/30)과 펄스 애니메이션**으로 5초간 강조됩니다.

### 2) 바탕화면 데스크톱 알림 (Desktop Notification)
- 프린터 드롭다운 하단의 **[상태 복구 알림]** 옵션을 체크하면 브라우저 권한을 승인하게 됩니다.
- 브라우저 창을 내려놓은 상태에서도 프린터가 준비 완료되면 다음과 같이 알림 메시지가 수신됩니다:
  > **[프린터 준비 완료]**  
  > [HP LaserJet Pro] 프린터가 오프라인에서 준비 완료 상태로 복귀했습니다.
