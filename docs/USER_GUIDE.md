# 📖 사용자 가이드 (User Guide)

Win11 PDF Print Helper는 대용량 PDF 문서 출력 시 발생할 수 있는 브라우저 튕김 및 프린터 메모리 멈춤 현상을 방지하도록 설계된 고급 분할 인쇄 프로그램입니다.

---

## 1. 기본 인쇄 프로세스

### 1) PDF 문서 불러오기
- 메인 화면 중앙의 드래그 앤 드롭 영역에 PDF 파일을 끌어다 놓거나, 클릭하여 파일을 선택합니다.
- 파일이 로드되면 문서 전체 페이지 수, 예상 묶음 수, 파일 용량이 표시됩니다.

### 2) 분할 단위 및 범위 설정
- **묶음 당 페이지 수**: 한 번에 프린터 스풀러로 전송할 페이지 단위(기본 50장)를 지정합니다.
- **인쇄 범위 설정**:
  - `전체 범위`: 문서 처음부터 끝까지 전체 인쇄
  - `페이지 지정`: 특정 시작/끝 페이지 지정
  - `홀수 페이지 / 짝수 페이지`: 단면 인쇄 후 수동 양면 출력을 위한 필터링

### 3) 간지(Slip Sheet) 옵션
- 묶음과 묶음 사이에 구분용 간지를 자동으로 삽입합니다.
- **커스텀 문구**: 간지에 인쇄될 제목 및 안내 텍스트 수정 가능
- **디자인 테마**: 심플, 강조, 테두리 스타일 지원
- **포인트 컬러**: 간지 헤더에 적용할 컬러 지정

---

## 2. 프린터 선택 및 실시간 모니터링

### 1) 프린터 선택 및 수동 동기화
- 우측 설정 패널의 **프린터 선택 드롭다운**에서 출력을 진행할 프린터를 선택합니다.
- 목록 바로 옆의 **[새로고침(Rotate)]** 버튼을 누르면 즉시 프린터 상태를 최신화합니다.

### 2) 최근 확인 시각 (Last Checked Timestamp)
- 드롭다운 내부 하단 및 상태 인디케이터 옆에 **`최근 확인: HH:MM:SS`** 시각이 표시되어 데이터의 신선도를 직관적으로 확인할 수 있습니다.

### 3) 프린터 상태 인디케이터 (.printer-status-indicator)
- **초록색 점 (준비 완료 / 연결됨)**: 정상적으로 인쇄할 수 있는 상태입니다.
- **빨간색 점 (오프라인 / 오류)**: 프린터 연결 또는 하드웨어 확인이 필요한 상태입니다.
- **진단 툴팁**: 상태 배지에 마우스를 올리면(Hover) 현재 상태 코드의 정확한 의미와 권장 조치 사항을 확인할 수 있습니다.

### 4) 프린터 상태 복구 알림 설정
- 프린터가 오프라인 상태였다가 케이블 연결/전원 켬 등으로 `준비 완료` 상태가 되면 배지가 녹색으로 강조(깜빡임 효과)됩니다.
- 프린터 드롭다운 하단의 **[상태 복구 알림]** 체크박스를 켜두시면 데스크톱 브라우저 알림으로 복구 사실을 바로 알려줍니다.

---

## 3. 대량 인쇄 진행 및 일시 중지 / 재개

### 1) 안전장치 (Pre-flight Status Check)
- 각 분할 묶음 전송 직전에 시스템이 프린터 상태를 실시간 검사합니다.
- 오프라인 또는 종이 없음 등의 장애 발생 시 자동으로 인쇄를 일시 중지하고 사용자에게 대화상자로 상황을 알려줍니다.

### 2) 일시 중지 및 개별 출력
- 인쇄 도중 언제든지 **[일시 중지]** 버튼을 눌러 작업을 제어할 수 있습니다.
- 특정 묶음만 재출력하고 싶다면 목록의 개별 묶음 **[출력]** 버튼을 사용할 수 있습니다.

---

## 4. 원클릭 사용자 정의 포트 자동 빌드 스크립트 (`build.bat`)

프로젝트 루트 디렉토리의 `build.bat` 배치 파일은 Node.js 및 의존성 환경을 자동으로 점검하고, 사용자 정의 포트 번호 기반으로 번들링 및 인스톨러 생성을 처리합니다.

### 1) 사용자 입력을 통한 포트 번호 지정
- 스크립트 실행 시 `사용할 포트 번호 입력 (기본값: 3000):` 프롬프트가 표시됩니다.
- 원하는 포트 번호(예: `8080`, `5173` 등)를 입력하거나 엔터를 누르면 기본값인 `3000` 포트로 빌드 환경변수가 적용됩니다.
- 대화형 메뉴 [4]번 옵션을 통해 빌드 진행 도중에도 언제든지 포트 번호를 재설정할 수 있습니다.

### 2) 더블 클릭 실행 (메뉴 선택 방식)
`build.bat` 파일을 탐색기에서 더블 클릭하면 지정된 포트로 대화형 콘솔 메뉴가 출력됩니다.
- **[1] 전체 자동 빌드**: 코드 타입 검사 ➔ Web PWA 빌드(`dist/`) ➔ Windows NSIS 설치 파일 생성(`release/`)
- **[2] Web PWA 빌드**: Web 배포용 번들 생성
- **[3] Electron 앱 빌드**: 데스크톱 설치 패키지(.exe) 생성
- **[4] 포트 번호 다시 변경하기**: 사용 포트 번호 재설정
- **[5] 패키지 재설치**: `node_modules` 재설치

### 3) 명령줄 인자 매개변수 (%1: 모드, %2: 포트번호)
명령 프롬프트(CMD) 또는 PowerShell에서 작업 모드와 포트 번호를 직접 인자로 전달할 수 있습니다:
```cmd
build.bat all 8080       :: 8080 포트로 전체 자동 빌드
build.bat web 8080       :: 8080 포트로 Web PWA 전용 빌드
build.bat electron 8080  :: 8080 포트로 Electron 설치 파일 빌드
```
